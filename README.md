# desafio-n8n-dio
Desafio de código n8n DIO

O presente repositório tem por objetivo guardar e preservar a criação de um workflow no n8n com ajuda da IA.

Foi utilizado o agente de IA da DIO construído dentro do Antigravity para dar esse suporte.

Na documentação, consta o prompt utilizado e a resposta do agente com o passo a passo para a criação do workflow.
